# AI-Powered Document Intelligence Platform

> Status: 🚧 In development (Phase 0 complete)

A production-style RAG platform for uploading documents (PDF/DOCX/TXT) and asking
grounded, cited questions over them. Built incrementally as a learning + portfolio project.

Full documentation (architecture, setup, evaluation, experiments) will be added
as each phase completes.

## Quickstart (Phase 0)

```bash
cp .env.example .env
docker compose up --build
```

Then check: `http://localhost:8000/health`
